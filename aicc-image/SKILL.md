# AICC 이미지 (Claude 에서 ChatGPT 이미지 생성 쓰기)

동봉 러너 `scripts/aicc-image.sh` 가 codex CLI 를 `codex exec` 로 실행해 ChatGPT 의
내장 `image_gen` 도구로 이미지를 만든다. ChatGPT 구독 OAuth 로 돌므로 API 키와
장당 과금이 없다. 장당 2~5분. 어떤 이미지 요청이든 이 통로를 쓴다.

## 0. 환경 자가 점검 (매번 제일 먼저, 왕초보 전제)

사용자가 아무것도 설치 안 했다고 전제하고, 아래를 순서대로 확인한다.
각 단계는 문제가 있을 때만 사용자에게 보이면 된다.

1. `command -v codex` → 있으면 3으로.
2. 없으면 `command -v npm` 확인.
   - npm 이 있으면: `npm install -g @openai/codex` 를 실행한다.
     권한 에러(EACCES)가 나면 사용자에게 알리고 `sudo npm install -g @openai/codex`
     를 사용자 승인 후 실행한다.
   - npm 도 없으면: `command -v brew` 확인. brew 가 있으면 `brew install node` 후
     위 npm 설치를 진행. brew 도 없으면 사용자에게
     "https://nodejs.org 에서 Node.js(LTS) 설치 프로그램을 내려받아 설치해 주세요.
     끝나면 저에게 '됐어'라고 말해주세요." 라고 안내하고 기다린다.
3. `codex login status` 실행. 출력에 "ChatGPT" 가 없으면 로그인이 필요하다.
   사용자에게: "ChatGPT 계정 연결이 1번 필요해요. 입력창에 `! codex login` 을
   입력하고, 열리는 브라우저에서 ChatGPT 로 로그인해 주세요." 라고 안내하고,
   완료 후 `codex login status` 로 재확인한다.
   (터미널이 아닌 환경이면 macOS 터미널 앱에서 `codex login` 실행을 안내.)
4. 전부 통과하면 사용자에게 설치 얘기는 꺼내지 않는다.

## A. 범용 이미지 생성·편집 (기본 모드)

사용자가 원하는 어떤 이미지든 만든다. 프롬프트는 Claude 가 쓴다.

1. 용도·비율·장수를 파악한다. 말 안 했으면 기본값: 1장, 가로 16:9.
2. 프롬프트는 영문 서술형 단락 하나로 쓴다. 키워드 나열 금지, 장면을 구체적으로
   (피사체·구도·조명·재질). 부정형 대신 긍정형 묘사. 이미지 안에 글자는 기본적으로
   넣지 않는다 (특히 한글은 깨지기 쉬움 — 꼭 필요하면 시도하되 결과를 확인).
3. 실행 (설치 위치가 `~/.claude/skills/aicc-image` 기준):

```bash
bash ~/.claude/skills/aicc-image/scripts/aicc-image.sh \
  --out "images/결과.png" --aspect "16:9" \
  "<영문 프롬프트>"
```

   - 기존 이미지 편집·참조: `-i <원본 절대경로>` 를 반복 첨부하고 프롬프트에
     "EDIT the attached image: ..." 라고 지시한다.
4. 실행 전에 "2~5분 정도 걸려요"라고 알려주고, 여러 장이면 한 장씩 순차 실행
   (병렬 금지 — codex 세션이 겹치면 느려진다).
5. 마지막 줄이 `OK <경로>` 면 성공. 결과 파일을 Read 로 열어 보여준다.
   `FAILED` 면 1회 재시도 후 에러 원문을 보여준다. exit 5(codex 없음)·exit 3
   (로그인 필요)은 0번 절차로 돌아간다.

## B. 그림일기 프리셋 (사진 + 일기 → 여행 기록 포스터)

"그림일기", "여행 기록 포스터" 요청이면 내장 프리셋을 쓴다. 왼쪽 원본 사진 +
오른쪽 고무도장·타자기 기록·일기가 조판된 4:3 포스터가 나온다.

1. 재료 3개: **사진**(끌어다 놓기), **날짜**(안 주면 오늘, "2026년 8월 27일" 형식),
   **일기**(사용자가 쓴 한국어 본문 — 요약·수정 없이 그대로).
2. 실행:

```bash
bash ~/.claude/skills/aicc-image/scripts/aicc-image.sh \
  --preset diary \
  --photo "/절대/경로/사진.jpg" \
  --out "diary/2026-08-27.png" \
  --date "2026년 8월 27일" \
  --diary "사용자 일기 본문 그대로"
```

3. 저장 위치를 말 안 했으면 `diary/YYYY-MM-DD.png`. 결과를 열어 일기 글자가
   깨졌는지 확인하고, 깨졌으면 같은 명령으로 1회 재생성한다.
4. 포스터 스타일 정본은 `references/prompt-template.txt`. 사용자가 스타일 변경을
   원할 때만 수정하고, `{{DATE}}` `{{DIARY}}` 자리는 남겨둔다.

## C. "일기장 앱 만들어줘" 요청이 오면

그림일기 프리셋을 심장으로 쓰는 로컬 웹앱을 만들어준다. 구조 원칙:

- 데이터는 폴더가 곧 데이터베이스: `diary/` 안에 날짜 이름 파일
  (`2026-08-27.png` + 같은 이름 `.txt` 에 일기 원문 저장).
- 앱은 이 폴더를 읽어 날짜 내림차순으로 쌓아 보여주는 한 페이지면 충분하다.
- 새 일기 추가 = 사진 업로드 + 일기 입력 → 서버가 `--preset diary` 로 러너 호출
  → 결과를 `diary/` 에 저장. 생성 중에는 "그리는 중" 상태를 보여준다.
- 기술 스택은 사용자 환경에서 제일 간단한 것. 왕초보 기본값:
  Node 단일 파일 서버 + HTML 한 장. 프레임워크 설치를 강요하지 않는다.

## 주의

- 러너의 codex 옵션(`--ephemeral --ignore-user-config`, approval never)은 빼지 말 것.
- OPENAI_API_KEY 가 있어도 러너가 지우고 실행한다 (구독 경로 고정). 바꾸지 말 것.
- 타인이 찍힌 사진은 본인 동의를 받으라고 안내한다.
